# rnmmp-core

The shared types and utils of the **Reticulum Network Mail Management Protocol** (rnmmp), imported as `rnmmp_core`.
Everything here is needed by both [`rnmmp-server`](../rnmmp-server) and [`rnmmp-client`](../rnmmp-client)

The protocol is specified in [the rnmmp spec](../../docs/spec/rnmmp.md).
